# aad-lapp-course

AaD 2.0 is a bilingual Sustainable Cities course prototype for Lappeenranta. Use only synthetic data in the hosted course pilot.

See [Render pilot deployment](DEPLOY_RENDER_PILOT.md) for setup. The deployment includes a React frontend, Spring Boot API and PostgreSQL.

Built on the 2025 Group 11 Adopt-a-Drain project. See the [original project README](UPSTREAM_README.md) for attribution and history.
